# dsh-fabric-system-prompt

Fabric-owned system prompt for DeepSeek Harness: one high-priority operational section capturing pi-fabric's well-tuned long-horizon disciplines, adapted to DSH, plus an authoritative `system-prompt/assemble` waterfall listener that minimizes the native DSH prose.

- The root export registers the `fabric:system-prompt` section (order 10, right after the persona), the visibility-gated `fabric:memory-guidance` section (order 114, populated when the session-query toolset is composed), and the minimization listener.
- `FABRIC_SYSTEM_PROMPT` carries the durable-coordination, compaction, memory/recall, Code-Mode, delegation, and error-recovery rules.
- `PRESERVED_SECTIONS` names the sections minimization keeps: identity, persona, plan policy, cordis toolset guidance, subagent reporting, the Code-Mode SDK/collapse rules, the DSH session-query guidance, the Fabric memory guidance, and the Fabric mesh guidance.
- Tool schemas, the dynamic runtime-context snapshot, and prompt variables are never filtered, so the model keeps the complete operational facts while the redundant per-tool prose is dropped.
