# @dsh-fabric/compaction

Deterministic Fabric summary compiler adapted to DSH's durable `CompactionEngine` transaction. It preserves bounded typed facts, graded history projections, exact failure identities, and a compact recent transcript without making a second model request. It folds selected DSH messages together with durable Fabric activity and native workflow lifecycle records, and accepts cumulative snapshots only from the newest matching Fabric provider/model boundary.

The package also ships the authoritative system-trusted Fabric agent-preset root. The bundle points DSH's host-resolved AgentPresets runtime at that immutable root, so linked installs retain one Cordis runtime and correct per-preset scoping. It masks the stock DSH compaction backend and tool-result pruner while retaining DSH's backend-independent `/compact` command, token meter, durable lock, replacement protocol, and session invariants. Creation mode includes both pinned Cordis composition/plugin authoring skills referenced by its preset.
